Get started.

Open a binary in the desktop app, navigate the graph, or build the native tools from source. Expand a topic for the practical steps.

Repository ↗ Release notes ↗
Open and inspect a binary
  1. Launch GandonPro.exe.
  2. Choose File → Open or press Ctrl + O.
  3. Select an executable or library. The entry function opens in the graph view.
  4. Use the Functions / Symbols tree to jump to functions, sections, imports and strings.
Navigate the graph and listing

Select a node to change the active address. Use the mouse wheel to zoom and drag to pan. Open the text listing, pseudocode or XREF tab for another view of the current binary. Press Home to fit the graph.

Build the native application

On Windows, install Visual Studio 2022 with the Desktop development with C++ workload and CMake 3.25 or newer. From a Developer PowerShell in the repository, run:

cmake --preset windows-msvc-x64
cmake --build --preset windows-msvc-x64-release

Debugger shortcuts

F2 toggles a breakpoint. F9 starts or continues the process; F6 pauses it. Use F7 to step into and F8 to step over.

Plugins and extensions

Native plugin examples and Python plugins live in the repository's plugins/ directory. See the project README and plugin API headers for the supported entry points.
